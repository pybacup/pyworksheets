# Foundation pilot: June 2024 Paper 1 (1MA1/1F)

Pilot completed locally on 10 October 2026 and subsequently approved. This report
records the pilot-only snapshot. See `gcse-foundation-processing-report.md` for
the subsequent full-bank import; nothing has been committed or pushed.

## Result

- **28 questions, 80 marks**, numbered 1-28 with no gaps or duplicate IDs.
- Every question has a compact questionFile, original-working-space workingQuestionFile and official answerFile: **84 individual PDFs**.
- Q22 spans source pages 16-17. Its compact version combines both parts into one page; its working-space version retains two pages. The other 27 questions each have one working-space page.
- All 28 official answer extracts match the correct Foundation mark scheme and question number. No uncertain or failed matches.
- Only the June 2024 P1 question paper and matching mark scheme were unpacked. Both 45-paper Foundation ZIPs remain in the repository; the other 44 papers were not processed.

## Preservation and shared architecture

All 1,069 pre-existing records remain exactly unchanged, including the 997 Higher questions and their classifications, compact PDFs, working-space PDFs and official answer references. No existing tracked PDFs were changed or removed. The index now contains 1,097 records: 997 GCSE Higher, 28 GCSE Foundation and 72 non-GCSE records.

The existing public HTML, CSS and JavaScript required no changes. The existing tier, paper, series, year, topic, subtopic and marks filters handle Foundation metadata directly. Both export checkboxes remain OFF by default. Answer exports use the selected question order, original official content and Foundation source headings on A4 portrait pages.

The audited plan records original source hashes, MediaBox crop coordinates and output hashes. Question bands are embedded as vector content without retyping mathematics. Compact versions remove original dotted lines and blank working areas while retaining every subpart, mark allocation, diagram and required grid. Working versions preserve continuous original question regions. Answers retain the complete official question-specific marking table and guidance; modified-large-print appendices and general page furniture are excluded.

## Classification

The six agreed GCSE topic groups are unchanged. Existing labels are reused for matching skills, including identical primary classifications for the seven questions shared with June 2024 Higher P1.

Seven additional reusable labels cover skills not previously named in the Higher taxonomy: Powers and roots; Bar charts; Function machines; Simplifying ratios; Order of operations; Range; Linear equations with brackets. These are ordinary mathematical labels, not Foundation-specific synonyms. Range and Order of operations are secondary tags.

## Reproduction

From the repository root:

```sh
node tools/exams/generate-foundation-pilot.cjs
node tools/exams/create-foundation-pilot-samples.cjs /path/to/output/pdf
node --test tests/*.test.cjs
node tests/exams-foundation-pilot.browser.cjs
python -m unittest discover -s tests -p 'test_*.py'
python -m unittest discover -s fell-results/importer/tests
```

Set PLAYWRIGHT_MODULE to the installed Playwright package for browser tests. Python extraction checks use pdfplumber, pypdfium2, Pillow and NumPy. The generator checks the reviewed source hashes and refuses conflicting existing records. The planning script is pilot-specific and must be visually reviewed if any boundaries are edited.

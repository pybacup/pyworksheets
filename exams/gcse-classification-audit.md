# GCSE Higher classification audit

Status: approved for publication, including all three primary-method review decisions.

- Questions checked: **997**, across **45 papers** (2017–2025).
- Classification metadata changed: **925** questions; primary topic/subtopic changed on **913**.
- Existing non-GCSE records preserved exactly: **72**. Total index records: **1,069**; no missing or duplicate IDs.
- Final distinct primary subtopics: **139**; distinct filter subtopics including secondary skills: **142**.
- Question PDFs and 45 GCSE source PDFs: SHA-256 checks confirm unchanged.

## Method and interpretation

Every question PDF was read through extracted mathematical content. 129 questions also received visual checks to resolve diagrams, powers, fractions, transformations and damaged text encoding. Classification was assigned question by question, not by renaming old metadata. The November 2017 P2 paper was checked visually throughout because its font encoding obscured much of its text.

One primary topic and subtopic identify the main assessed skill. Secondary topics/subtopics record substantial additional skills or separately assessed parts; they do not create duplicate question records. Counts in the primary column sum to 997. The filter column includes secondary skills, so those counts overlap. A mixed-topic question may offer subtopics from both of its topics in the existing dropdown; this is the existing data model, not a new filtering behaviour.

Trigonometry is consistently placed in Geometry and Measures, including trigonometric graphs and equations. Three-bracket expansion is distinct from expanding sums of single brackets. Supplied linear simultaneous equations are distinct from forming them from context, and from systems involving a quadratic. Forming-and-solving classifications describe a suitable main method even when a one-variable alternative exists. Generic Transformations is retained only for combinations or questions assessing multiple transformations. Proportion equations is retained for questions combining direct and inverse relationships. Surds remains a valid secondary skill on a mixed geometric-sequence question; most surd questions now use the more precise Simplifying surds or Rationalising denominators labels.

## Verification

All checks passed locally:

- JavaScript suite: **78/78 tests** (`node --test tests/*.test.cjs`), covering exam data, filtering, selection, PDF layout and existing games.
- Python suite: **4/4 tests** (`python -B -m unittest discover -s fell-results/importer/tests -v`).
- All five Chrome acceptance suites passed: `exams-classification.browser.cjs`, `exams-gcse-bank.browser.cjs`, `exams-gcse.browser.cjs`, `exams-results.browser.cjs` and `exams-practice.browser.cjs`. Run with `PLAYWRIGHT_MODULE` pointing to the installed Playwright package.
- Six topic dropdown choices and **186 topic/subtopic combinations** matched the revised index exactly; changing topic reset and repopulated its subtopics.
- **18 combined paper/series/year/topic/subtopic/marks scenarios** matched the expected question IDs. Select All selected only visible matches, retained prior selections, and did not duplicate them.
- Real P1/P2/P3 and June/November previews opened successfully. All **997 individual question PDFs** were loaded and validated by the bank test; their existing relative links and source paths remain valid.
- A real **267-question Algebra selection** (including secondary Algebra classifications) exported to **122 standard A4 pages**. Every selected question's actual board, tier, paper, paper code, year, series, question number and marks was found in the exported source headings. Six sampled output pages were visually inspected.
- The **72-question Further Maths export**, desktop/iPad/mobile layouts, touch/keyboard selection, ordering, removal, totals and export-error handling passed the existing acceptance tests.
- Before/after comparison and the regression checksum confirm that only GCSE classification fields changed: every other field and all 72 non-GCSE records remain identical, in the same order. All 1,069 IDs remain unique.
- SHA-256 comparison confirmed all **997 question PDFs and 45 source PDFs** are unchanged. `git diff --check` passed.

The generated test booklet is a local review artifact outside the repository. Production HTML, CSS, JavaScript, worksheet functionality and game files were not changed.

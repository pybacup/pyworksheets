# GCSE Higher official answers: final processing report

Completed locally: 10 October 2026. Samples subsequently approved for publication.

## Coverage

- 45 official Pearson Edexcel Higher mark schemes matched to the existing bank.
- 974 new answer extracts plus the 23 approved June 2024 P1 pilot extracts: **997/997 questions covered**.
- 997 unique answer paths and unique file hashes; no missing, duplicate or unresolved matches.
- 1,015 answer pages, including 18 questions with two-page mark schemes.
- Each paper retains its existing 80 marks; the bank totals 3,600 marks.

## Extraction and preservation

The extraction plan records paper, year, series, question, source PDF SHA-256, source-page crop coordinates and output SHA-256. Official cover/table identities and continuous question numbering were checked against the existing index. Original PDF content is embedded without rewriting answers. Table headings, mark codes, alternative methods, diagrams and relevant guidance are retained. Blank tails and empty guidance columns are trimmed only when no content is present; unrelated modified-large-print appendices are excluded.

Rotated source pages are normalized before cropping, preserving vector content and original proportions. Source files themselves are unchanged. Continuation regions remain in source order, including very short continuations.

All 2,119 previously committed PDFs were verified byte-for-byte unchanged. All 1,069 existing records were preserved apart from the 974 new answerFile references; the 23 pilot references were already present. Compact PDFs, working-space PDFs, marks, classifications and non-GCSE records are unchanged.

## Verification

- JavaScript: **88 tests passed**, zero failures.
- Browser: **all seven suites passed**, including desktop, iPad/mobile layouts, basket selection, compact/working-space exports and answer downloads.
- Python: **four tests passed**.
- All 1,015 answer pages rendered successfully and passed comparison with their official source regions. Comparison tolerates raster antialiasing and table-border differences; it is not a semantic proof of every marking instruction.
- Visually reviewed 74 representative/continuation pages spanning all 45 papers, plus all 14 pages of the final mixed sample. No clipping, orientation or missing-continuation problems found in this review.
- Index/path/hash checks cover every one of the 997 answers, source identity, expected question sequence and continuation count.

## Export behaviour

Also create answers / mark scheme remains OFF by default and resets when the dialog opens. When enabled, answers use the same basket order and actual source metadata as the practice paper. Both booklets use A4 portrait (595.28 x 841.89 points); short answers flow onto shared pages. An explicit Download answers / mark scheme link supports browsers that block a second automatic download.

Missing answer metadata or a failed answer fetch produces a clear question-specific error. Neither booklet is offered as a successful pair until both builds finish. Existing compact and working-space selection behaviour remains intact.
